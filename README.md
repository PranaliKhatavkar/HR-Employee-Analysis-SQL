# HR Employee Analysis using SQL

## 📌 Project Overview

This project focuses on analyzing employee data using **MySQL** to identify useful HR insights related to employee distribution, salary, experience, performance, job satisfaction, overtime, and attrition.

## 🎯 Project Objectives

* Analyze the overall employee workforce
* Compare employee count across departments
* Analyze salary distribution and average salary
* Identify highly paid employees
* Analyze employee experience
* Study employee performance and job satisfaction
* Analyze employee attrition
* Use SQL JOINs to combine employee and department information

## 🛠️ Tools & Technologies

* **MySQL**
* **MySQL Workbench**
* Excel Dataset

## 📊 Dataset

The dataset contains employee-level information such as:

* Employee ID

## 📈 Key Analysis

The project analyzes questions such as:

1. What is the total number of employees?
2. Which department has the most employees?
3. What is the average salary?
4. Which department has the highest average salary?
5. Who are the highest-paid employees?
6. How many employees have left the company?
7. What is the overall attrition rate?

## 🔗 SQL JOIN Analysis
A separate `departments` table is used to demonstrate an **INNER JOIN** between employee and department information.
